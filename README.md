# 智取店勤務助手

蝦皮智取店巡店、科目回報、班表與勤務資料管理工具。

**目前版本：v8.0.0（Supabase Sync）**

## 線上使用

https://wsoft0628.github.io/store-report/

## 主要功能

- 今日勤務儀表板與跨店巡店進度
- 巡店科目 4、5、6、8、15 填表與完整回報複製
- 班表匯入、日／月檢視及 Excel／PDF 報表
- 臨時勤務支援、固定週／月勤務與異常交接
- SOP／勤務資料庫、設備資料及 QR 管理
- 手機快速輸入、內建計算機與離線保留
- JSON 本機備份、還原與安全快照

## v8.0.0 雲端架構

- 使用 Supabase 帳號密碼登入
- 管理員建立、核准並設定 Admin／Editor／Viewer 權限
- Supabase 為日常跨裝置同步的唯一來源
- 使用版本鎖防止不同裝置互相覆蓋
- 本機資料可離線使用，恢復連線後再同步
- Google Drive 僅保留為使用者主動執行的人工備份，不再自動登入或同步

## 權限

| 角色 | 雲端讀取 | 雲端寫入 | 帳號管理 |
|---|---:|---:|---:|

| Editor | ✅ | ✅ | — |

## 部署檔案

- `index.html`：正式應用程式
- `store-app-sw.js`：離線快取 Service Worker

## 注意事項

- 不開放自行註冊，帳號由管理員建立及核准。
- 發生資料版本差異時，請先確認本機與雲端內容再選擇，避免誤覆蓋。
- Google Drive 不參與 Supabase 資料版本判定。
